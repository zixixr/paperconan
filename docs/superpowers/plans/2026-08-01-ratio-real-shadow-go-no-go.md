# Ratio 真实 Shadow Go/No-Go 执行记录

- 日期：2026-08-01
- 范围：短行 ratio 臂的 M2/M2.5 离线验证
- 结果：**no-go；不进入 M3–M5，不改变生产 detector**

> 本记录只描述统计信号和数据不一致的筛查能力，不对人员或数据成因作判断。真实语料、候选身份与人工
> 复核细节均留在 gitignored 的 `recheck/`，本文只提交聚合数字。

## 目标

验证统一量化重建、prediction bits 和表级结构分类能否在真实低精度盲区中留下值得人工复核的孤立关系，
并按设计文档预先规定的硬闸决定是否替换现有 ratio 臂。

## 执行顺序

1. 冻结 212 条路径 / 167 份不同内容的 manifest。
2. 只选择「保留全部旧候选条件、唯独移除精度资格后新可达」的 142 条路径 / 121 个去重 sheet。
3. 离线运行 M1 量化重建与 M2 计分，不接生产输出。
4. 先按列域和显式 block 判断局部 family/series，再判断表级重复变换。
5. 对残余候选人工查看上下文；修正列域串联、跨 block 吞并和量化公共池三个问题。
6. 对候选行触顶的 sheet 补跑中段、尾段连续窗口，记录而不掩盖 coverage 限制。
7. 依据真实锚点与曲线风险的硬闸作 go/no-go。

## 结果

主窗口产生 1,333,730 个 raw run，1,246,374 个可计分 run；其中 1,359 条有向 relation 超过 20 bits，
对应 991 个去重行窗。最终去向为：

| context | relation | 去重行窗 / 摘要 |
|---|---:|---:|
| `ambiguous_within_context` | 656 | 430 个行窗 |
| `proportional_family` | 643 | 508 个行窗 / 88 个 family |
| `proportional_series` | 6 | 4 个行窗 / 3 个 series |
| `quantized_common_pool` | 54 | 49 个行窗 / 45 个摘要 |
| **isolated ratio** | **0** | **0** |

18 个 sheet 的候选池触顶；其中一个窗口耗尽离线预算。对触顶 sheet 的主窗口、中段窗口和尾段窗口分别
重跑，三组最终孤立关系均为 0。该结果是有明确 coverage 限制的抽样结论，不外推成对未扫描区间的证明。

## 审查中形成的实现约束

- 不同列域不能因共享行节点而互相摧毁上下文；relation 只有在列域至少重叠 2 列且覆盖较短域一半时才
  共享结构分类。
- 显式 block/panel 分隔是硬边界；跨 block 关系必须进入表级判断。
- 高频量化格不是删除规则。只有同一列的 source 与 target 两侧都属于公共格才屏蔽，再用原 `n_tests`
  重算 prediction bits；只有独特列低于 20 bits 才折叠为 `quantized_common_pool`。
- relation 的原始证据、公共列和屏蔽后的分数必须保留；只有正反方向都跌破门槛才统一折叠，否则两个方向
  都保留为孤立 context。

## 决策

当前冻结语料未建立一条经人工确认、且明显不同于周围结构的真实孤立 ratio 锚点，只有 synthetic planted
fixture 提供正例。因此命中设计文档的停止条件：M3–M5 不开工，生产 detector、精度资格与 `_same_band`
保持不变。

重新打开本设计需要至少满足一项：

- 扩充真实语料，并用同一 shadow 与 coverage 审计重跑；
- 提供一条已知真实候选，确认它能过 M1/M2 且在完整表结构中仍可分。

重新打开后仍需同时满足曲线硬闸，不能用降低分数门槛或按小数位分支绕过结构问题。
