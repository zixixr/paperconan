# 设计：短行比例复用改用统一的量化重建与预测信息量

- 日期：2026-07-30
- 状态：设计已收敛，待实现计划
- 涉及：`detect_short_row_reuse` 的 `scaled_row_reuse`（ratio）臂
- 不涉及：`identical_row_reuse`、`offset_row_reuse` 与长段检测器的判定改造

> ⚠️ 中立措辞红线：本检测器产出的是**统计信号 / 数据不一致 / 待作者澄清 / data
> inconsistency**，不构成对任何人的指控。原始记录、图注、Methods、作者答复与期刊/机构复核才能
> 定性。文档、代码、变量名、报告文案一律遵守此红线。

---

## 1. 决策摘要

当前 `detect_short_row_reuse` 只允许每格至少记录到 3 位小数的值进入短比例 run。这个逐格硬门槛没有
同时考虑记录精度、值域和确认列数，因此会漏掉「8 列、2 位小数」这类比「3 列、高精度」更强的关系。

本设计不新增一个「2 位小数探测器」，也不把现有 `>=3` 位小数逻辑视为正确基线。ratio 臂改成一条覆盖
所有记录精度的统一路径：

1. **关系成立**：是否存在一个常数 `k`，使 `A × k` 按 B 行的有效记录精度重新取整后，能逐格重建 B。
2. **证据强度**：除去确定 `k` 的一个格子后，剩余格子一共被这个常数预测了多少信息。
3. **结构解释**：这是跨面板的孤立比例关系，还是同一曲线、单位换算、量化网格或整张比例表的构造。

关系由「量化区间有共同交集」严格定义；强度用 `prediction_bits` 表示；结构解释在关系发现之后做，不再
由精度候选池间接决定。

本设计明确否决原方案的 sheet 经验分布概率：

```text
p_i = sheet 中落在预测窗口内的值数 / sheet 数值总数
E   = n_tests × Πp_i
```

它在小表中必然把被匹配的 `b_i` 自己计入窗口，实际 `p_i >= 1/N`，与原方案按量化格点计算的例子不一致；
同时还要求行内各列近似独立，并把多面板、多量纲数据混成一个背景分布。`chance_expectation` 因此不能按
其名字解释为可靠的偶然概率。

## 2. 问题与已知证据

### 2.1 当前硬门槛把精度当成逐格资格

ratio run 的每个格子目前必须满足：

```text
fractional_digits >= 3
```

这与 run 有多少确认列无关。一格被挡掉还会把连续 run 截断，可能让两边都短于最低列数。

前一轮 #56 已把两个问题拆开：

- `_is_short_hp`：格子是否能进入 run；
- `_can_pin_a_ratio`：相邻行对由哪个 pass 处理。

但它们仍围绕固定精度和固定容差工作，而且 `_is_short_hp` 还间接决定候选行、`_rare` 的背景池和
`_same_band` 的 band 成员。改变精度范围会改变表格结构解释；历史实测中，改用所有数据行定义 band
曾令语料产出减少 61%。所以这次不能再把「放宽一个谓词」当作局部修改。

### 2.2 低小数位覆盖数字需要重新核实

本地 212 份补充材料中，含至少 30 个非整数值的数值表按**中位小数位**统计：

| 中位小数位 | sheet 数 | 占比 |
|---|---:|---:|
| 0–2 位 | 170 | 23.7% |
| 3 位 | 80 | 11.1% |
| 4 位 | 61 | 8.5% |
| >=5 位 | 407 | 56.7% |

这证明大量表以 0–2 位小数为主，但不能单凭中位数推出这些 sheet 对当前检测器「完全不可见」：一个中位数
为 2 的表仍可能有足够多的 3 位以上数值组成候选行。M0 必须直接统计：

- 完全没有 ratio 候选行的 sheet 数；
- 有候选行、但目标关系因中间低精度格而被截断的 sheet 数；
- 只有低精度行对、当前完全未比较的 sheet 数。

在这组直接数字出来之前，不再把 23.7% 写成完整盲区比例。

### 2.3 一个当前会漏的强关系

合成面板（B 是 A 统一乘以常数后写回到 2 位小数）：

```text
          Rep1    Rep2    Rep3    Rep4    Rep5    Rep6    Rep7    Rep8
Vehicle  42.13   58.91   19.37   71.20   33.84   26.55   49.02   61.78
Treated  35.43   49.54   16.29   59.87   28.46   22.33   41.22   51.95
逐列比值 0.84097 0.84094 0.84099 0.84087 0.84102 0.84105 0.84088 0.84089
```

取 `k ≈ 0.840916` 时，8 个 `k × A` 全都能四舍五入回对应的 B；最大预测误差约为 0.0037，小于
2 位小数的半个末位单位 0.005。逐列允许的 `k` 区间还有共同交集：

```text
0.840869 <= k <= 0.840941
```

这条关系有一个用于确定 `k` 的格子和 7 个确认格。当前输出为空；相反，3 位以上小数、只有 3 列的关系
可以报告。强弱顺序因此颠倒。

### 2.4 已测误报面

原设计在 40 张表 × 30 行 × 8 列的合成台架上观察到：

| 数据形态 | 小数位 | 连中3列 | 连中4列 | 连中5列 | 连中6列 |
|---|---:|---:|---:|---:|---:|
| 跨两个数量级（1–100） | 1 | 1 | 0 | 0 | 0 |
| 百分比（0–100） | 1 | 0 | 0 | 0 | 0 |
| 小量程读数（1–20） | 1 | 2 | 0 | 0 | 0 |
| 归一化值（集中在 1.0 附近） | 1 | 1867 | 286 | 40 | 6 |
| 归一化值 | 2 | 33 | 1 | 0 | 0 |
| 归一化值 | 3 | 0 | 0 | 0 | 0 |
| 同一条平滑曲线上的行 | 1 | 16549 | 14487 | 10904 | 6381 |
| 同一条平滑曲线上的行 | 2 | 5180 | 1710 | 467 | 85 |
| 同一条平滑曲线上的行 | 3 | 76 | 4 | 1 | 0 |

这说明：

- 低精度本身不是主要误报源；
- 值域相对量化步长过窄时，预测一个格子的意义很小；
- run 越长，一个常数解释的确认格越多；
- 平滑曲线不是独立随机值，任何只靠独立零假设的概率都会误读，必须由结构上下文解释。

## 3. 设计原则

### 3.1 一个 ratio 路径覆盖所有精度

不按 0、1、2、`>=3` 位小数分支，不保留「旧高精度路径 + 新低精度路径」的最终结构。开发期间可以让
新旧算法 shadow 并行以比较输出，但正式切换后旧 ratio 两个 pass 删除。

### 3.2 把三类问题分层

| 层 | 回答的问题 | 不负责什么 |
|---|---|---|
| 量化重建 | 一个 `k` 能否逐格重建目标行 | 不判断是否值得报告 |
| 预测信息量 | 这个 `k` 解释了多少确认信息 | 不解释曲线、单位或表格语义 |
| 结构分类 | 关系在表中的上下文是什么 | 不改变数学上是否能重建 |

任何一层都不得再通过「是否为高精度候选」暗中改变另一层的输入。

### 3.3 旧语料输出是比较基线，不是真值

当前 307 条 / 22 文件用于定位行为变化，但验收不要求净数量不变。每一条丢失和新增都要逐文件解释；
已提交的强关系 fixture 必须保留，除非经结构证据证明它属于另一种明确关系类型，并同步修改设计和回归
测试。不得只因为总数相同就接受一组 `+N/-N`。

## 4. 有效记录步长

### 4.1 为什么不能直接数 float 的小数位

`Sheet` 当前只保留 float 数值。`71.20` 和 `71.2` 进入检测器后完全相同，原始末尾零已经丢失。因此本版
不能声称知道「该单元格原本记录到几位小数」。

本设计先使用**行级推断的有效记录步长**，不扩大到解析 Excel 样式或保存 CSV 原始词法；报告必须明确
它是推断值。

### 4.2 确定性推断规则

对一行参与比较的有限数值：

1. 用现有的十进制 float 表示逻辑计算每格可见小数位 `d_cell`，最多计 10 位。
2. 取该行所有有限数值 `d_cell` 的众数为 `d_row`；众数并列时取较大的小数位。
3. 每格有效小数位：

```text
d_eff(i) = max(d_cell(i), d_row)
q_i      = 10 ** (-d_eff(i))
```

`max` 的含义是：同行大多数值为 2 位小数时，把 float 中的 `71.2` 保守地读成同一面板精度的 `71.20`；
若一格确实保存了更多小数，不把它降粗。若某格真实记录得比同行更粗，这个推断会给它更窄的允许区间，
方向是少报而不是放宽匹配。

全整数行得到 `d_row=0, q=1`，不再因整数身份被绝对排除。短小计数矩阵的有效格点很少，会由
`prediction_bits` 得到低分；长段、宽值域且可由一个常数逐格重建的整数行则可以成为待复核统计信号。

finding 写入：

```text
precision_source = "row_inferred"
quantum_a
quantum_b
```

这里的 `quantum_a/quantum_b` 是 run 内有效步长的排序去重摘要；不是虚构的原始格式元数据。

## 5. 统一量化重建核

### 5.1 使用有方向的生成模型

对每个无序行对同时检查两个方向：

```text
A -> B：B 可能由已有的 A 乘以 k 后，按 B 的有效精度写回
B -> A：A 可能由已有的 B 乘以 k 后，按 A 的有效精度写回
```

源行数值按当前存储值使用；只有目标行承担写回量化误差。这比把 A、B 都当作某个未知潜在向量的独立
取整更符合本检测器寻找的「复制后统一缩放」关系。因果方向未知，所以两个方向都检查。

### 5.2 每列给出一个允许的 `k` 区间

对方向 `A -> B`，若 `a_i` 有限且非零、`b_i` 有限，目标步长为 `q_bi`：

```text
lo_i = (b_i - q_bi/2) / a_i
hi_i = (b_i + q_bi/2) / a_i
I_i  = [min(lo_i, hi_i), max(lo_i, hi_i)]
```

浮点比较只允许一个固定的机器误差余量，不再另设随小数位变化的 `_SHORT_ROW_RTOL`。

特殊情况：

- `a_i = 0, b_i != 0`：关系在该列断开；
- `a_i = 0, b_i = 0`：与任意 `k` 相容，但不缩窄区间、不增加确认信息；
- NaN / 非有限值：关系断开；
- `k` 的共同区间包含 1：在当前量化精度下无法区分于无缩放，ratio 不报告；identical 臂独立判断；
- `k` 接近整十次幂：交给单位换算结构分类。

### 5.3 连续 run 是区间共同交集

连续列 `[s, e]` 构成比例 run，当且仅当其所有有信息列满足：

```text
max(lo_s ... lo_e) <= min(hi_s ... hi_e)
```

内部候选至少需要：

- 2 个有信息列：一个确定 `k`，至少一个确认；
- 2 个不同的源值；
- run 长度 `< _ROW_REL_MIN_COLS`，保持与长段检测器的职责边界。

最低 2 列是关系可检验性的定义，不是最终报告门槛；是否报告由 `prediction_bits` 决定。扫描器返回所有
不被更长同向 run 包含的 maximal runs，再由证据分数选择同一行对的代表关系。

一个行对可能同时有多个 maximal run。选择顺序固定为：

1. `prediction_bits` 较高；
2. 有信息确认列较多；
3. run 较长；
4. 起始列较早；
5. 方向按规范化行坐标排序。

由共同区间选择最终 `k` 时，取使最大标准化写回误差最小的点；若最优点不唯一，取最优区间中点。报告：

```text
ratio_interval = [k_lo, k_hi]
ratio
max_rounding_residual
```

其中：

```text
rounding_residual_i = abs(b_i - k*a_i) / q_bi
```

区间定义保证有信息列的残差不超过 `0.5 + machine_epsilon`。

## 6. 统一证据强度：prediction bits

### 6.1 人工判断的形式化

人工看到一条比例关系时，实际在做：

1. 用一个格子估计 `k`；
2. 用同一个 `k` 预测其余格子；
3. 看预测跨越多少不同数值、精确到哪个量化格点、连续成功多少次。

`prediction_bits` 把「一个参数解释了多少后续记录」写成信息压缩量，而不是声称得到精确 p 值。

### 6.2 目标行的有效格点数

对目标 run 的非零有信息值，定义稳健范围：

```text
R = max(median(q_bi), percentile90(b_run) - percentile10(b_run))
```

百分位使用确定性的线性插值。每个确认格在这个范围内大约有：

```text
G_i = max(1, R / q_bi)
```

个可区分量化位置。若数据集中在 1.0 附近且只记录到 1 位小数，`G_i` 很小；若数据跨越几十个单位并记录
到 2 位小数，`G_i` 可达数千。

### 6.3 分数

run 的第一个有信息格作为 anchor，不计预测收益。其余有信息格贡献：

```text
raw_prediction_bits = Σ log2(G_i)
```

一张 sheet 的实际搜索机会数按已进入 pair loop 的行对确定。若行对的重叠宽度为 `m_pair`，两个方向各有
`m_pair - 1` 个能容纳至少两列的潜在起点；即使某个起点随后立即被 NaN、零或文本打断，也仍计入搜索
成本：

```text
n_tests =
    2 × Σ实际检查的无序行对 max(0, m_pair - 1)
```

系数 2 是两个生成方向。若候选池或计算预算提前截断，只统计实际检查过的机会，并照常记录 coverage 不完整。

最终：

```text
prediction_bits = raw_prediction_bits - log2(max(1, n_tests))
```

默认报告门槛：

```text
PAPERCONAN_SHORT_ROW_MIN_PREDICTION_BITS = 20
```

20 bits 表示在扣除搜索描述成本后，这个单一比例模型至少节省约一百万分之一量级的网格编码空间；它是
可比较的模型压缩分数，不命名为概率，也不解释为对原因的定性。

M2 必须在语料和零假设台架上验证 20 bits。若它不能同时满足 M2 验收，停止并修订本设计；不得在实现中
无记录地调到一个刚好通过当前语料的数字。

### 6.4 强弱顺序

同一公式自然同时使用：

- 确认列数；
- 记录步长；
- 相对值域；
- 实际搜索次数。

§2.3 的 8 列 2 位小数例子约有 7 个确认格，每格覆盖数千个可能位置，扣除小表搜索成本后仍远高于
20 bits。3 列高精度关系只有 2 个确认格；它仍可能超过 20 bits，但分数应低于前者。M2 用固定 fixture
直接断言：

```text
score(8列、2位小数) > score(3列、高精度)
```

## 7. 结构分类与误报控制

### 7.1 ratio 候选行不再由精度决定

ratio 臂的数据行最低定义：

- 至少 2 个有限、非零数值；
- 至少 2 个不同数值；
- 行标签不像坐标轴或索引；
- 候选生成不调用 `_is_short_hp`。

候选池仍受 `_SHORT_ROW_MAX_ROWS_PER_SHEET` 和 `_SHORT_ROW_BUDGET` 约束，截断必须写 coverage。M3 必须
测量扩大候选域后的候选数、预算耗尽率和运行时间。

`identical` / `offset` 臂暂时继续使用现有候选定义；这不是按精度复制 ratio 探测器，而是三个关系类型
暂时拥有各自的数学资格。ratio 只有一条覆盖所有精度的路径。

### 7.2 布局结构独立于 ratio 精度

为 ratio 上下文建立 `row_layout`：

- 一行有至少 2 个有限数值且至少 2 个不同数值，即可作为数值数据行；
- 空白行、纯文本标题行和轴标签行是分隔行；
- 连续数据行组成 structural block；
- block 成员不读取 `_is_short_hp`、`prediction_bits` 或是否形成 finding。

这替换 ratio 臂当前由候选行集合反推 `_same_band` 的做法。

### 7.3 关系发现后再分类

量化重建和 `prediction_bits` 先产生 qualifying relation，随后分类：

| context class | 判定 | 处理 |
|---|---|---|
| `isolated_cross_block_ratio` | 两行分属不同 structural block，关系孤立 | 输出待复核统计信号 |
| `partial_within_block_ratio` | 同 block，但只覆盖部分可比较列 | 输出；报告部分区间 |
| `within_block_global_scale` | 同 block 且覆盖 >=85% 可比较列 | 先进入 block 内关系图，再按下述确定顺序处理 |
| `proportional_series` | 邻近多行在相同列域形成连续比例关系 | 作为曲线/序列结构解释，不输出 pair finding |
| `proportional_family` | 同一 block 内比例关系图密集 | 输出至多一条 `medium` 表级模式，禁止逐对占满 finding cap |
| `power_of_ten_conversion` | `k` 在量化区间内与 `10^n` 相容 | 作为单位重述，不输出孤立复用 |
| `quantized_common_pool` | run 值来自高频量化网格/平台 | 不输出孤立复用 |

系列与比例族使用确定性的 block 内关系图：

- 节点是 structural block 中的数据行；
- 只有覆盖 `>=85%` 可比较列的 qualifying global-scale relation 才形成边；
- `proportional_series` 是至少 3 个连续数据行组成的链，链上每一对相邻行都有边；
- `proportional_family` 是至少 4 个节点的连通分量，且无向边密度
  `2E / (V*(V-1)) >= 0.5`；
- 同一分量同时满足两者时，密集的 `proportional_family` 优先；否则连续链按
  `proportional_series` 处理。

block 内 global-scale edge 的处理顺序固定为：

1. 先折叠所有 `proportional_family`，使用既有 `scaled_row_reuse` kind、`medium` severity 和
   `context_class="proportional_family"`，每个分量至多一条；
2. 剩余边中，连续链和单独的相邻行边都作为曲线/序列结构解释，不输出 pair finding；
3. 剩余的非相邻、非密集 global-scale edge 以
   `context_class="within_block_global_scale"` 输出，不能仅因同 block 而静默删除。

两类聚合都以 structural block 为边界。跨多个明确分隔面板的 qualifying relation 永远不因 block 内图
密集而删除。以跨 block 关系为边再建一张图：单边输出普通 `isolated_cross_block_ratio`；含至少 2 条边
的连通分量折叠成一条跨面板统计信号，并保留 block 数、行数、边数与示例行。

### 7.4 现有结构守卫的迁移

- `_near_power_of_ten`：改为判断 `ratio_interval` 是否包含整十次幂，而不是只比较均值与固定 RTOL。
- `_rare`：继续防量化网格，但频率池改为 source / target 各自 structural block 的全部 ratio 数据行，
  并按各自有效量化步长归桶；任一侧来自高频共同池就分类为 `quantized_common_pool`，不再只统计
  `_is_short_hp` 候选。
- `_vector_is_patterned`：保留为行语义特征；等差/等比坐标行不进入孤立 ratio 输出。
- `_same_band`：ratio 臂删除，职责由 `row_layout` 和关系后的 context class 接管。

## 8. 代码边界

建议在 `_audit.py` 先落成可独立测试的纯函数，不顺带做文件拆分：

```text
_effective_row_quantums(values)
_directed_ratio_interval(a, b, q_target)
_scan_quantized_ratio_runs(source, target, target_quantums)
_ratio_prediction_bits(run, n_tests)

```

`detect_short_row_reuse` 中：

1. identical / offset 按现状生成；
2. ratio 为所有精度构建一个候选池；
3. 每个行对统一检查两个方向；
4. 计算 `prediction_bits`；
5. 对过门槛关系做结构分类与聚合；
6. 与 identical / offset 做一次行对级 arm 选择，确保一个行对不重复输出。

正式切换后删除：

- `_longest_hp_ratio_run`；
- `_longest_lowdiv_ratio_run`；
- ratio 对 `_is_short_hp` 的依赖；
- ratio 的 pass 1 / pass 2 ownership；
- 若无其他调用者，删除 `_can_pin_a_ratio`、`_row_can_pin_a_ratio`、`_lowdiv_accept`。

`_SHORT_ROW_RTOL` 若仍被 identical / offset 使用则保留并改名到对应关系；不得继续充当 ratio 的隐藏容差。

## 9. 否决的替代方案

### 9.1 为两位小数增加独立路径

否决。它会制造新的 `2 / >=3` 边界、重复候选和守卫逻辑，也无法解释一位小数长段或高精度短段的相对
强弱。shadow 双跑只用于迁移验证，不能成为最终架构。

### 9.2 用 sheet ECDF 计算 `chance_expectation`

否决。原因：

- 被匹配值自己保证 `p_i >= 1/N`，窄窗口下分数退化为 sheet 大小函数；
- 文档示例按理论格点计算，和 ECDF 定义不是同一个模型；
- 多面板 sheet 混合量纲，整表池既不保证保守，也不保证同分布；
- `Πp_i` 要求列间独立，重复测量、时间序列和曲线数据不满足；
- 结构性关系仍需额外守卫，复杂度没有换来可靠概率语义。

### 9.3 每张 sheet 做穷举置换检验

暂不采用。它比 ECDF 更贴近当前数据，但短行 sheet 可用置换太少，无法稳定分辨小概率；破坏列对齐后仍不能
解释同一曲线和共享对照，计算成本也高。保留为离线校准工具，不进入首版运行时。

## 11. 完成后的行为

- 不再存在 ratio 的 `fractional_digits >= 3` 资格线。
- 一位、两位、三位和更高精度共用同一个量化重建定义和同一个 20-bit 报告门槛。
- 8 列 2 位小数可以比 3 列高精度得到更高分。
- 同一条关系可由读者用 `ratio_interval`、有效步长和最大写回误差直接复核。
- 平滑曲线与比例表由结构上下文分类，不被错误包装成独立随机值的极小概率。
- 报告的是统计信号和数据不一致，不是原因判断；共享对照、派生数据、单位换算和表格构造仍需结合图注、
  Methods、原始记录与作者说明解释。
